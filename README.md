## 🚀 Getting Started

Want to explore or run these projects locally?

### 1. Clone the repository

```bash
git clone https://github.com/ANSHPATIL2007/javaProjects.git
```

### 2. Navigate to the project directory

```bash
cd javaProjects
```

### 3. Open the project

Open the repository in IntelliJ IDEA or your preferred Java IDE.

### 4. Compile and run

For a standalone Java file:

```bash
javac Main.java
java Main
```

Make sure Java JDK is installed on your system.
